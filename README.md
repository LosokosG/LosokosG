### Hi, I'm Mateusz

I build LLM applications and automations, and the tooling that keeps AI coding agents honest while they work. Based in Szczecin, Poland. Most of my code is TypeScript and Python.

**Work I can't open-source** (private repos, short descriptions):

- [Kameleon](https://kameleon.gg): my own AI and automation platform. Document search (RAG), CRM and integrations live in one system, so something built for one client can be adapted for the next.
- Brayn: a Discord support bot that answers from a project's knowledge base and hands a conversation to a human when it can't. I built it end to end; by my own estimate it's used on about 100 Discord servers.
- Nexus Terminal, client work for GalFi: it collects community posts from X, YouTube and TikTok, scores them with an LLM against a rubric, and feeds XP and leaderboards.
